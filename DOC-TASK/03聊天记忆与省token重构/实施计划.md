# 聊天记忆与省 Token 重构 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 按任务逐条实施。步骤用 `- [ ]` 复选框标记进度。**每个 Task 跑完测试再 commit，不要跳测试。**

**Goal:** 在不降低回复质量（Opus 始终写回复）的前提下，给微信 Bot 加上持久化长期记忆，并用「DeepSeek 当秘书 + Prompt Caching + 智能文件上下文」三条机制大幅降低 Claude token 消耗。

**Architecture:** 把 1385 行的 `bot.js` 按职责拆成独立模块。每轮对话前，DeepSeek（便宜模型）做一次「秘书」调用，从长期记忆和文件锚点里**挑出本轮相关的部分**；`context-builder` 把选中的内容按「静态在前、动态在后」组装成带 `cache_control` 的 Anthropic 请求；Opus 读着这份精选且可缓存的上下文写回复。回复发出后，DeepSeek 异步把本轮值得长期记的事抽取进记忆。

**Tech Stack:** Node.js v22（ESM）、纯 `fetch`、本地 JSON 文件存储（无新依赖、无向量库）。Claude 走 Anthropic Messages 格式（`/v1/messages`）；DeepSeek 走 OpenAI 兼容格式（`/v1/chat/completions` + `response_format: json_object`）。测试用项目现有的 `node:test` 风格 + `local-channel` HTTP 测试通道。

## 0. 给开发者的背景（零上下文也能上手）

**这是什么项目**：微信 iLink Bot，后端接 Claude 做 AI 自动回复。一份 `bot.js` 被多个「实例」共享，PM2 用 `cwd` 把每个实例指向 `instances/<name>/`，所有路径都是相对路径（`config.json`、`session.json`、`logs/`、本计划新增的 `memory/`）。生产实例：`tsja`、`wife`。

**两条不可动摇的设计约束**（已与项目负责人确认）：
1. **Opus 永远写用户可见的回复**，绝不降级到便宜模型。
2. **DeepSeek 只当幕后秘书**：选上下文、维护记忆、压缩旧对话，从不写一个字给用户。

**已有但本计划要利用/改造的东西**：
- `callAIWithUsage`（[bot.js:657](../../bot.js)）：调 Claude，要抽成 `lib/ai-client.js` 并加缓存。
- `callSummaryAI`（[bot.js:620](../../bot.js)）：飞书摘要用的 DeepSeek 文本调用，**保持不动**。
- `fileAnchors` / `getHistoryForUser` / `buildFileAnchors`（[bot.js:325-432](../../bot.js)）：现有文件锚点机制，机械 `turnCount` 淘汰 + 每轮全量注入，要被本计划替换。
- `recordChatTurn`（[feishu-summary/index.js](../../feishu-summary/index.js)）：每轮对话后**异步**写飞书的成熟管线，记忆抽取要复用同样的异步模式。
- `config.json` 里已有 `router_api_key / router_base_url / router_model`（DeepSeek 配置），目前只被飞书当 fallback，本计划让秘书和记忆抽取**正式使用**它们。

**测试通道**（关键，先读懂再写测试）：
- `LOCAL_TEST_PORT` 环境变量启用本地 HTTP 通道，`bot.js` 不连微信，改从本地 inbox 收消息（[bot.js:1304-1323](../../bot.js)）。
- 注入：`POST /local/inbox/text|file|image`；观察回复：`GET /local/outbox?since=N&wait_ms=M`（长轮询）；查内部状态：`GET /local/state?user_id=...`（走 `snapshotForProbe`）；清理：`POST /local/reset`。
- `tests/runner.js` 启动一个真实 `bot.js` 子进程（实例 `instances/test-local/`），顺序跑 `tests/scenarios/*.test.js`。该实例 `config.json` 指向**真实** `api.b.ai`(Opus) 和真实 DeepSeek。
- 单元测试在 `tests/unit/`，用项目自带的极简 `test()` helper（见 [tests/unit/feishu-summary.test.js](../../tests/unit/feishu-summary.test.js)），**靠依赖注入避免真网络**（如 `fakeRunner`）。本计划所有调模型的函数都要支持注入 `callJSON`，单测不打网络。

**Anthropic Prompt Caching 要点**（本计划的省钱核心，务必理解）：
- 在 `text` block 上加 `"cache_control": { "type": "ephemeral" }` 标记缓存断点；`system` 可以是「文本块数组」从而支持 `cache_control`。
- 缓存是**前缀匹配**：断点之前的内容必须逐字节一致才命中。所以组装顺序必须「最稳定的在最前」。
- 有**最小可缓存长度**（Claude 主力模型约 1024 token）。低于此长度加 `cache_control` 不会命中（白标记甚至中转可能报错）。本计划用字符阈值 `CACHE_MIN_CHARS` 兜底，只在内容够大时才加断点。
- 命中后响应 `usage` 多出 `cache_creation_input_tokens`（写缓存，1.25x 价）和 `cache_read_input_tokens`（读缓存，0.1x 价）。**现有 `normalizeAiUsage` 没解析这两个字段，必须扩展**。
- ephemeral TTL 约 5 分钟，每次命中刷新。聊天间隔 >5min 会丢缓存（属正常，不影响正确性）。
- ⚠️ **中转 `api.b.ai` 是否透传 `cache_control` 未知**。Phase 1 必须**先实测**：若 `cache_read_input_tokens` 始终为 0，则判定不支持，自动降级为无缓存（功能不受影响，只是省不到 input）。

## 2. 数据模型

**长期记忆文件**：`instances/<name>/memory/<safeUserId>.json`（`safeUserId` = userId 把 `:`/`/` 等替换成 `_`）。

```json
{
  "version": 1,
  "userId": "local:default",
  "profile": [
    { "id": "p_xxx", "text": "在中国国企工作，负责文档撰写、会议纪要", "createdAt": 1700000000000, "updatedAt": 1700000000000, "hits": 3 }
  ],
  "episodes": [
    { "id": "e_xxx", "summary": "讨论装修预算，倾向简约风", "tags": ["装修"], "ts": 1700000000000 }
  ],
  "updatedAt": 1700000000000
}
```
- `profile`：缓慢演化的**持久事实**（身份、偏好、在跟进的事、常提到的人）。上限 `MEMORY_MAX_PROFILE`，超了淘汰 `hits` 最少且最旧的。
- `episodes`：对话摘要，**新的在前**。上限 `MEMORY_MAX_EPISODES`，超了从尾部丢。

**文件锚点**（`file-context.js` 内存态，不持久化）：
```js
{ id: "f_xxx", fileName: "报告.docx", content: "[用户上传了文件: 报告.docx]\n\n<正文>", idleTurns: 0 }
```

## 3. 日志规范（务必统一，方便排查）

所有新子系统都用**带标签的单行日志** + 写一条结构化事件到 `logs/debug_messages.jsonl`（复用现有 `debugLog`）。标签固定如下：

| 标签 | 触发点 | 单行格式示例 |
|---|---|---|
| `[秘书]` | 每次 selectContext | `[秘书] user=local:default 候选(文件=2,记忆=12,事件=8) → 文件=[f_a] 事件=[e_3,e_7] 画像=2 (412ms,in=320,out=40) reason=ok` |
| `[秘书]` 降级 | DeepSeek 超时/失败 | `[秘书] user=... 降级(timeout 6000ms) → 带全部文件+近5事件` |
| `[记忆]` | 抽取写入 | `[记忆] user=... +画像"在国企工作"(12→13) +事件"聊装修预算"` |
| `[记忆]` 跳过 | 无新事实 | `[记忆] user=... 无新增（仅写事件摘要）` |
| `[缓存]` | 每次 callClaude | `[缓存] user=... 写=1840 读=0 (首轮,未命中)` / `写=0 读=1840 (命中100%)` / `禁用(中转不支持)` |
| `[上下文]` | 每次 buildRequest | `[上下文] user=... system=2.1k(缓存) 文件=1(缓存,18k字) 事件=4 历史=6条 ≈11.2k token` |

结构化事件（写 jsonl）：`{event:"secretary_decision", user, candidates, selected, reason, latency_ms, usage}`、`{event:"memory_extract", user, new_facts, episode}`、`{event:"claude_usage", user, input, output, cache_creation, cache_read}`、`{event:"context_built", user, ...meta}`。

降级/异常一律 `console.log` 打出原因，**绝不静默吞**（catch 里至少打一行）。

### Task 1.2：`callClaude` —— 接收已组装请求 + 缓存降级

约定：`callClaude` 接收**已经组装好的** `{system, messages}`（来自 Phase 5 的 context-builder），自己不拼上下文。这样职责单一、好测。

- [ ] **Step 1: 写实现**（这是 IO 函数，主要靠 Phase 8 端到端验证；此处先写实现再补一个降级单测）
```js
// lib/ai-client.js （追加）
import { setTimeout as sleep } from "timers/promises";

let cacheSupported = true;
export function isCacheSupported() { return cacheSupported; }
export function _setCacheSupported(v) { cacheSupported = v; } // 仅测试用

const RETRY_DELAYS = [2, 4, 8, 16, 32];

// 去掉 system 与 messages 里所有 cache_control（降级时用）
function stripCacheControl({ system, messages }) {
  const strip = (block) => {
    if (block && typeof block === "object" && "cache_control" in block) {
      const { cache_control, ...rest } = block; return rest;
    }
    return block;
  };
  const sys = Array.isArray(system) ? system.map(strip) : system;
  const msgs = messages.map(m => Array.isArray(m.content)
    ? { ...m, content: m.content.map(strip) } : m);
  return { system: sys, messages: msgs };
}

// onLog: (line) => void  用于注入日志（默认 console.log），便于测试
export async function callClaude({ system, messages, config, cache = { enabled: false }, onLog = console.log }) {
  const headers = {
    "Authorization": `Bearer ${config.api_key}`,
    "content-type": "application/json",
    "User-Agent": "claude-cli/2.0.76 (external, cli)",
  };
  const url = `${config.base_url}/v1/messages`;
  const useCache = cache.enabled && cacheSupported;
  let payload = { model: config.model, max_tokens: 4096, system, messages };
  if (!useCache) payload = { model: config.model, max_tokens: 4096, ...stripCacheControl({ system, messages }) };

  let lastError;
  for (let attempt = 0; attempt <= RETRY_DELAYS.length; attempt++) {
    try {
      const res = await fetch(url, { method: "POST", headers,
        body: JSON.stringify(payload), signal: AbortSignal.timeout(180000) });
      if (!res.ok) {
        const errBody = await res.text().catch(() => "");
        // 中转可能因 cache_control 报错：探测到就永久降级并立刻重试无缓存版本
        if (useCache && /cache|unsupported|invalid.*control/i.test(errBody)) {
          cacheSupported = false;
          onLog(`[缓存] 中转疑似不支持 cache_control（HTTP ${res.status}），永久降级为无缓存`);
          payload = { model: config.model, max_tokens: 4096, ...stripCacheControl({ system, messages }) };
          continue;
        }
        onLog(`[AI] HTTP ${res.status} 响应体: ${errBody.slice(0, 500)}`);
        throw new Error(`HTTP ${res.status}`);
      }
      const data = await res.json();
      const text = data.content?.[0]?.text;
      if (!text) throw new Error("响应中未找到文本内容");
      const usage = normalizeUsage(data.usage);
      const hit = usage.cache_read_input_tokens > 0;
      onLog(`[缓存] 写=${usage.cache_creation_input_tokens} 读=${usage.cache_read_input_tokens} (${useCache ? (hit ? "命中" : "未命中") : "未启用"})`);
      return { text, usage };
    } catch (e) {
      lastError = e;
      if (attempt < RETRY_DELAYS.length) {
        onLog(`[AI] 第 ${attempt + 1} 次失败（${e.message}），${RETRY_DELAYS[attempt]}s 后重试`);
        await sleep(RETRY_DELAYS[attempt] * 1000);
      }
    }
  }
  onLog(`[AI] 已重试 ${RETRY_DELAYS.length} 次最终失败: ${lastError?.message}`);
  return { text: "AI 接口暂时不可用，请稍后再试。",
    usage: normalizeUsage({}) };
}
```

// memory/store.js
import fs from "fs";
import path from "path";

export function memoryDir() { return process.env.MEMORY_DIR || "memory"; }
function safe(userId) { return String(userId).replace(/[^a-zA-Z0-9_.-]/g, "_"); }
export function memoryPath(userId) { return path.join(memoryDir(), safe(userId) + ".json"); }

export function genId(prefix) {
  return `${prefix}_${Date.now().toString(36)}${Math.floor(Math.random() * 1e6).toString(36)}`;
}

export function loadMemory(userId) {
  try {
    const raw = fs.readFileSync(memoryPath(userId), "utf-8");
    const m = JSON.parse(raw);
    return { version: 1, userId, profile: [], episodes: [], updatedAt: 0, ...m };
  } catch {
    return { version: 1, userId, profile: [], episodes: [], updatedAt: 0 };
  }
}

export function saveMemory(userId, mem) {
  fs.mkdirSync(memoryDir(), { recursive: true });
  mem.updatedAt = Date.now();
  const file = memoryPath(userId);
  const tmp = file + ".tmp";
  fs.writeFileSync(tmp, JSON.stringify(mem), "utf-8");
  fs.renameSync(tmp, file); // 原子替换，防写一半损坏
}

// memory/store.js （追加）
function normText(s){ return String(s||"").trim().replace(/\s+/g," "); }

export function applyNewFacts(mem, facts, cap) {
  const existing = new Set(mem.profile.map(f => normText(f.text)));
  for (const raw of facts || []) {
    const text = normText(raw);
    if (!text || existing.has(text)) continue;
    existing.add(text);
    const now = Date.now();
    mem.profile.push({ id: genId("p"), text, createdAt: now, updatedAt: now, hits: 0 });
  }
  if (mem.profile.length > cap) {
    // 淘汰：hits 升序、createdAt 升序（最不常用且最旧先走）
    mem.profile.sort((a, b) => (a.hits - b.hits) || (a.createdAt - b.createdAt));
    mem.profile = mem.profile.slice(mem.profile.length - cap);
  }
  return mem;
}

export function addEpisode(mem, summary, tags, cap) {
  const text = normText(summary);
  if (!text) return mem;
  mem.episodes.unshift({ id: genId("e"), summary: text, tags: tags || [], ts: Date.now() });
  if (mem.episodes.length > cap) mem.episodes = mem.episodes.slice(0, cap);
  return mem;
}

export function touchProfile(mem, ids) {
  const set = new Set(ids || []);
  for (const f of mem.profile) if (set.has(f.id)) { f.hits++; f.updatedAt = Date.now(); }
  return mem;
}

export async function callDeepSeekJSON(config, { system, user, timeoutMs = 6000 }) {
  const base = process.env.ROUTER_BASE_URL || config.router_base_url || config.base_url;
  const apiKey = config.router_api_key || config.api_key;
  const model = config.router_model || config.model;
  const t0 = Date.now();
  const res = await fetch(`${base}/v1/chat/completions`, {
    method: "POST",
    headers: { "Authorization": `Bearer ${apiKey}`, "content-type": "application/json" },
    body: JSON.stringify({
      model,
      messages: [{ role: "system", content: system }, { role: "user", content: user }],
      max_tokens: 512, temperature: 0,
      response_format: { type: "json_object" },
    }),
    signal: AbortSignal.timeout(timeoutMs),
  });
  if (!res.ok) {
    const body = await res.text().catch(() => "");
    throw new Error(`deepseek HTTP ${res.status}: ${body.slice(0, 200)}`);
  }
  const data = await res.json();
  const content = data.choices?.[0]?.message?.content;
  if (!content) throw new Error("deepseek 无 content");
  return { data: JSON.parse(content), usage: data.usage || {}, latencyMs: Date.now() - t0 };
}

         MEMORY_RECALL_MAX_EPISODES } from "./constants.js";

export function buildSelectionPrompt({ userText, profile, episodes, files, fileSummaryLen = SECRETARY_FILE_PREVIEW_CHARS }) {
  const fileLines = files.map(f => `[${f.id}] ${f.fileName}: ${f.content.slice(0, fileSummaryLen).replace(/\n/g, " ")}...`);
  const epiLines = episodes.map(e => `[${e.id}] ${e.summary}`);
  const profLines = profile.map(p => `[${p.id}] ${p.text}`);
  const system = `${SECRETARY_MARKER}\n你是上下文调度助手。只输出 JSON，不要解释。`;

${profLines.join("\n") || "(无)"}

可选历史事件摘要：
${epiLines.join("\n") || "(无)"}

可选已上传文件：
${fileLines.join("\n") || "(无)"}

判断哪些与"当前消息"相关。规则：
- 用户在询问/引用某文件 → file_ids 加该文件 id；明显聊别的 → 不加
- 与当前消息相关的画像/事件 → 加对应 id；闲聊问候可都为空
- 不确定就宁可多带（尤其文件）
只输出：{"profile_ids":[...],"episode_ids":[...],"file_ids":[...]}`;
  return { system, user };
}

export function parseSelection(obj, valid) {
  const pick = (arr, set) => (Array.isArray(arr) ? arr.filter(id => set.has(id)) : []);
  return {
    profileIds: pick(obj?.profile_ids, valid.profileIds),
    episodeIds: pick(obj?.episode_ids, valid.episodeIds),
    fileIds: pick(obj?.file_ids, valid.fileIds),
  };
}

export function fallbackSelection({ profile, episodes, files, recallMaxEpisodes = MEMORY_RECALL_MAX_EPISODES }) {
  return {
    profileIds: profile.map(p => p.id),
    episodeIds: episodes.slice(0, recallMaxEpisodes).map(e => e.id),
    fileIds: files.map(f => f.id),
    reason: "fallback",

// secretary.js （追加）
export async function selectContext({ userText, profile, episodes, files }, opts = {}) {
  const { config, callJSON = (c, p) => callDeepSeekJSON(c, p),
          timeoutMs = SECRETARY_TIMEOUT_MS, recallMaxEpisodes = MEMORY_RECALL_MAX_EPISODES } = opts;
  // 快路径：无任何候选 → 不调模型
  if (!profile.length && !episodes.length && !files.length) {
    return { profileIds: [], episodeIds: [], fileIds: [], reason: "empty", latencyMs: 0, usage: {} };
  }
  const { system, user } = buildSelectionPrompt({ userText, profile, episodes, files });
  try {
    const { data, usage, latencyMs } = await callJSON(config, { system, user, timeoutMs });
    const valid = {
      profileIds: new Set(profile.map(p => p.id)),
      episodeIds: new Set(episodes.map(e => e.id)),
      fileIds: new Set(files.map(f => f.id)),
    };
    const sel = parseSelection(data, valid);
    return { ...sel, reason: "ok", latencyMs: latencyMs ?? 0, usage: usage || {} };
  } catch (e) {
    return { ...fallbackSelection({ profile, episodes, files, recallMaxEpisodes }),
             latencyMs: 0, usage: {}, reason: `fallback:${e.message}` };
  }
}

// file-context.js
import { FILE_ANCHOR_MAX_CHARS, FILE_ANCHOR_TOTAL_CHARS, FILE_ANCHOR_MAX_FILES } from "./constants.js";
import { genId } from "./memory/store.js";

const anchors = new Map(); // userId → [{id, fileName, content, idleTurns}]

// 两级截断（从旧 bot.js buildFileAnchors 迁移）
export function buildFileAnchors(files) {
  const step1 = files.slice(0, FILE_ANCHOR_MAX_FILES).map(f => ({
    ...f, text: f.text.length > FILE_ANCHOR_MAX_CHARS ? f.text.slice(0, FILE_ANCHOR_MAX_CHARS) : f.text,
  }));
  const total = step1.reduce((s, f) => s + f.text.length, 0);
  if (total <= FILE_ANCHOR_TOTAL_CHARS) return step1;
  const ratio = FILE_ANCHOR_TOTAL_CHARS / total;
  return step1.map(f => ({ ...f, text: f.text.slice(0, Math.floor(f.text.length * ratio)) }));
}

export function addAnchors(userId, files) {
  const list = anchors.get(userId) || [];
  for (const f of buildFileAnchors(files)) {
    list.push({ id: genId("f"), fileName: f.fileName,
      content: `[用户上传了文件: ${f.fileName}]\n\n${f.text}`, idleTurns: 0 });
  }
  anchors.set(userId, list);
}

export function getAnchors(userId) { return anchors.get(userId) || []; }
export function anchorCount(userId) { return (anchors.get(userId) || []).length; }
export function clearAnchors(userId) { return anchors.delete(userId); }

// 本轮被选中的归零 idle，其余 +1，超过 evictAfter 淘汰
export function applyFileSelection(userId, selectedIds, evictAfter) {
  const list = anchors.get(userId);

// context-builder.js
import { CACHE_MIN_CHARS } from "./constants.js";

export function renderProfile(profile) {
  if (!profile.length) return "";
  return "\n\n[长期记忆·关于用户]\n" + profile.map(p => `- ${p.text}`).join("\n");
}
export function renderEpisodes(episodes) {
  if (!episodes.length) return "";
  return "[相关历史]\n" + episodes.map(e => `- ${e.summary}`).join("\n");
}

// cache = { enabled, minChars }
export function buildRequest({ systemPrompt, profile = [], files = [], episodes = [], history = [], userContent, cache = {} }) {
  const minChars = cache.minChars ?? CACHE_MIN_CHARS;
  const cacheOn = !!cache.enabled;

  // 1) system：基础提示词 + 核心画像（静态，最前）
  const systemText = systemPrompt + renderProfile(profile);
  let system;
  if (cacheOn && systemText.length >= minChars) {
    system = [{ type: "text", text: systemText, cache_control: { type: "ephemeral" } }];
  } else {
    system = systemText; // 纯字符串
  }

  const messages = [];
  let cachedBlocks = cacheOn && Array.isArray(system) ? 1 : 0;

  // 2) 文件锚点（会话内稳定，可缓存）；最后一个够大的文件打断点
  const lastCacheableFileIdx = (() => {
    if (!cacheOn) return -1;
    for (let i = files.length - 1; i >= 0; i--) if (files[i].content.length >= minChars) return i;
    return -1;
  })();
  files.forEach((f, i) => {
    if (i === lastCacheableFileIdx) {
      messages.push({ role: "user", content: [{ type: "text", text: f.content, cache_control: { type: "ephemeral" } }] });
      cachedBlocks++;
    } else {
      messages.push({ role: "user", content: f.content });
    }
  });

  // 3) 召回事件（每轮变化，不缓存）
  const epiText = renderEpisodes(episodes);
  if (epiText) messages.push({ role: "user", content: epiText });

  // 4) 滑动窗口历史（不缓存）
  for (const h of history) messages.push({ role: h.role, content: h.content });

  // 5) 当前消息（字符串或 content blocks）放最后
  messages.push({ role: "user", content: userContent });

  const totalChars = systemText.length + files.reduce((s, f) => s + f.content.length, 0) + epiText.length;
  return { system, messages, meta: {
    cachedBlocks, fileCount: files.length, episodeCount: episodes.length,
    systemChars: systemText.length, totalChars,
  } };
}

// memory/extract.js
import { EXTRACT_MARKER, MEMORY_EPISODE_SUMMARY_CHARS,
         MEMORY_MAX_PROFILE, MEMORY_MAX_EPISODES } from "../constants.js";
import { callDeepSeekJSON } from "../lib/deepseek.js";
import * as defaultStore from "./store.js";

export function buildExtractPrompt({ userText, aiReply, profile }) {
  const known = profile.map(p => `- ${p.text}`).join("\n") || "(无)";
  const system = `${EXTRACT_MARKER}\n你是记忆抽取助手。只输出 JSON，不要解释。`;
  const user = `已知用户画像：
${known}

本轮对话：
用户：${String(userText).slice(0, 1000)}
助手：${String(aiReply).slice(0, 800)}

任务：
1) new_facts：本轮中**值得长期记住**的新事实（身份/稳定偏好/在跟进的事/重要人物）。临时信息、一次性问答不要记。已知画像里有的不要重复。没有就空数组。
2) episode_summary：${MEMORY_EPISODE_SUMMARY_CHARS} 字以内概括本轮聊了什么。
3) tags：0-3 个关键词。
只输出：{"new_facts":[...],"episode_summary":"...","tags":[...]}`;
  return { system, user };
}

export function parseExtraction(obj) {
  return {
    newFacts: Array.isArray(obj?.new_facts) ? obj.new_facts.filter(x => typeof x === "string" && x.trim()) : [],
    episodeSummary: typeof obj?.episode_summary === "string" ? obj.episode_summary.trim() : "",
    tags: Array.isArray(obj?.tags) ? obj.tags.slice(0, 3) : [],
  };
}

export async function extractAndStore({ userId, userText, aiReply }, opts = {}) {
  const { config, store = defaultStore, callJSON = (c, p) => callDeepSeekJSON(c, p),
          caps = { maxProfile: MEMORY_MAX_PROFILE, maxEpisodes: MEMORY_MAX_EPISODES },
          onLog = console.log } = opts;
  try {
    const mem = store.loadMemory(userId);
    const { system, user } = buildExtractPrompt({ userText, aiReply, profile: mem.profile });
    const { data } = await callJSON(config, { system, user, timeoutMs: 8000 });
    const { newFacts, episodeSummary, tags } = parseExtraction(data);
    const before = mem.profile.length;
    store.applyNewFacts(mem, newFacts, caps.maxProfile);
    if (episodeSummary) store.addEpisode(mem, episodeSummary, tags, caps.maxEpisodes);
    store.saveMemory(userId, mem);
    onLog(`[记忆] user=${userId} +画像${mem.profile.length - before}条 +事件"${episodeSummary.slice(0,20)}"`);
  } catch (e) {
    onLog(`[记忆] user=${userId} 抽取失败（已忽略）: ${e.message}`);
  }
}
